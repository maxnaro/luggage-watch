\subsection{Object Detection and Tracking Performance}

\subsection{Validation Protocol for Abandonment Logic}

Due to the unavailability of frame-level annotations for the test set, a
temporal event-based ground truth was established. An event was defined by a
single temporal anchor (the frame of abandonment) and a spatial region of
interest (ROI). The pipeline was evaluated using a temporal tolerance of $\pm
	90$ frames ($\approx 3$ seconds depending on the frame rate) to account for
manual annotation variability.

\subsubsection{Ground Truth Annotation Methodology}
\label{sec:ground_truth_annotation_methodology}

Due to the temporal nature of abandoned luggage, traditional frame-by-frame
bounding box annotations were impractical. Instead, the ground truth was
established using a single-point event anchoring method.

For each video in the dataset, the annotation process followed these steps:

\begin{enumerate}
	\item \textbf{Scene Triage and Parameter Definition}
	      \begin{itemize}
		      \item Reviewal of the entire video sequence to determine if a genuine abandonment
		            event has occurred, setting the \texttt{has\_abandonment} flag accordingly.
		      \item Based on the camera's perspective, focal length, and requirements of the
		            scenario, definition of the spatial and temporal limits for that specific
		            video; i.e., determining the radius of ownership and the temporal window for
		            abandonment detection as \texttt{radius\_px} and \texttt{threshold\_s}
		            respectively.
	      \end{itemize}
	\item \textbf{Event Anchoring}
	      \begin{itemize}
		      \item If an abandonment event is identified, the annotator scrubs through the video
		            to identify the exact moment the bag transitions from being unattended to being
		            abandoned.
		      \item Calculate the frame number corresponding to this moment, by determining where
		            the owner breaches the ownership radius, and then moving forward in time by the
		            defined threshold to anchor the event.
		      \item This frame number is then recorded as the \texttt{true\_abandon\_frame}. This
		            metric acts as the temporal anchor against which the pipeline's detection
		            latency is measured.
	      \end{itemize}
	\item \textbf{Negative Sample Logging}
	      \begin{itemize}
		      \item If the video contains no abandonment event (e.g., a bag is left unattended but
		            the owner returns within the defined temporal threshold), the video is tagged
		            with \texttt{has\_abandonment} set to \texttt{false}. The frame and ROI fields
		            are left null.
		      \item Negative samples are useful for testing the pipeline's resilience against false
		            positives.
	      \end{itemize}
\end{enumerate}

Annotations are saved in a structured \texttt{JSON} format
(listing~\ref{lst:annotation_format}), producing a comprehensive ground truth
dataset that is strictly tied to the logic of the abandonment detection
pipeline.

\subsubsection{Annotation Script}
\label{sec:annotation_script}

To facilitate the annotation process, a custom script was developed. This
script provided a user-friendly interface for annotators to review video
footage, define spatial and temporal parameters and record the necessary
information for each video. This was implemented using Python and OpenCV,
allowing for video playback control and scrubbing. An example of the script's
interface is shown in figure~\ref{fig:annotation_script_screenshot}.

\subsubsection{Datasets Used for Validation}

Annotations were performed on the eleven examples from the ABODA dataset
mentioned in section~\ref{sec:suspicious_luggage_dataset}. These examples, the
ground truth annotations derived from them, and the annotation script
(section~\ref{sec:annotation_script}) can be found in a forked repository at
\url{https://github.com/maxnaro/ABODA}. The resulting annotated dataset
consisted of eleven samples with one or more abandonment events.
